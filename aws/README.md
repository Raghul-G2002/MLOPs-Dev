# AWS MLOps

This folder is a learning scaffold for the AWS MLOps path described in
[`aws_mlops_research.md`](../aws_mlops_research.md).

## Tracks

- [`development/`](development/): notebook-first experiments using S3, SageMaker Feature Store, SageMaker training, Model Registry, lineage, and batch outputs.
- [`prod-version/`](prod-version/): script-oriented building blocks for a later containerized workflow with ECR and a deployment target such as SageMaker, ECS, or EKS.

Start with the development README. The production scripts are intentionally
small and explicit so deployment decisions can be made later.
